<CardGrid stagger>
	<Card title="导入数据" icon="open-book">
		直接读取 NMR（JEOL、Bruker、Varian/Agilent、JCAMP-DX）、LC–MS（Waters、
		SCIEX WIFF、mzML）、粉末 XRD、XPS、AFM 和膜片钳（ABF2）文件，以及 CSV、TSV、
		Excel 和 Origin 表格——无需转换。见[支持的格式](/zh-cn/guides/supported-formats/)。
	</Card>
	<Card title="配合 AI 客户端" icon="puzzle">
		连接 Claude Desktop 或其他 MCP 客户端，让它导入数据、生成并调整图、排布面板。
		它做的修改都出现在你的画板上，可以先预览，也可以撤销。
	</Card>
	<Card title="交互式处理" icon="setting">
		以有序步骤列表构建处理管线：切趾、FFT、相位与基线校正——实时预览，完整撤销。
	</Card>
	<Card title="分析" icon="magnifier">
		峰与积分、DOSY / 弛豫与 IV 分析、支持自定义模型的曲线拟合，
		以及经典统计——全部汇入联动数据表。
	</Card>
	<Card title="出版" icon="document">
		在无限画板上排布图形，按出版级预设导出 SVG、PDF、PNG 或 TIFF。
	</Card>
