---
title: 三维 NMR 谱
description: 打开、处理和浏览三维 NMR 采集数据。
---

通过常规打开或拖放入口导入受支持的 Bruker 常规采样三维实验目录。
Plotium 在后台处理原始数据，并在普通工作区显示二维频率平面。
明确选择处理后的文件时尊重该选择；提取出的二维谱仍按二维数据打开，
不会替代完整三维采集。

使用谱图旁的平面控件选择固定采集轴、逐层浏览或输入 ppm。
核种标签包含采集维度，以区分具有两个氢轴的实验。
输入 ppm 后选择最近的采样平面，并显示实际坐标。
切层复用处理后的体数据，保留缩放和等高线设置；切换方向时保留各采集轴的位置。

正负等高线保留信号符号，灵敏度通过已有控件调整。
复数分量保留用于[相位校正](#相位校正)。

保存普通 `.plotium` 项目会保留采集快照、处理参数和当前平面。
重新打开项目不要求原始实验目录仍可访问。
首版面向常规采样三维数据，不扩展三维 NUS 重建或四维浏览。

## 相位校正

选中三维谱，选择 **Process → Correct → Phase** 打开相位面板。
编辑前先确认面板中的目标谱名。各采集轴（F1/F2/F3）显示核种
（缺失时为 `unknown`）和当前显示方向：横轴、纵轴或固定轴。
切换平面只更新显示方向，相位参数始终对应原来的采集轴。

调整所需轴的 **PH0** 和 **PH1**，点击 **Apply** 后在谱图上检查结果。
Apply 从源数据重新计算整卷，替换上次的相位设置；可浏览其他切片检查校正效果。
当前显示的二维切片不支持拖动调相，修改参数也没有实时预览。

**Pivot** 以 ppm 设置一阶相位的参考位置。移动枢轴时会自动补偿 PH0，
保持相位校正结果不变。允许范围延伸至最后一个采样点之外一个采样间隔；
轴上没有可用的均匀 ppm 网格时，该控件不可用。

- **Discard changes** 恢复已应用的参数，不触发重算。
- **Stop calculation** 取消指明的计算，保留所做的修改。
- 关闭面板保留修改，正在运行的计算继续。

计算期间可以浏览平面或切换谱，结果仍应用于启动时指定的谱。
如果源数据或已应用的相位设置发生变化，未应用的修改会被丢弃；
重新打开面板即可从当前设置开始编辑。

## 自动化

CLI 工具目录和 MCP 与桌面使用相同核心操作。
通过 `data.import` 导入，通过 `processing.inspect` 查看维度和相位参数。
`nmr.volume.edit` 使用从零开始的 `fixed_axis` 和 `index` 选择平面。
可选的 `phases` 数组包含三个对象，各有 `p0_degrees`、`p1_degrees`
和 `pivot_fraction`（0–1）。调用前查看操作 schema，并使用稳定的数据集 ID
和当前文档版本。之后的数据预览和渲染面向当前平面。

三维体数据暂不提供通用数值表格导出，因为现有二维表格格式无法保留固定坐标
和采集轴身份。保存项目可保留数据，展示用途可导出图像。

## 三维峰编辑

选择 **Analyze → Peaks** 或峰面板中的 **Pick peaks**，然后点击谱图添加人工观测。
点击标记选中峰，拖动改变当前显示的两个坐标，按 Delete 删除。
峰面板也提供 Delete 按钮，以及三轴坐标和备注编辑器。
每次拖动或完成一次文字编辑产生一条撤销记录。

单击峰表记录即可选中、定位到对应切片并居中，同时保留缩放尺度。
Previous 和 Next 用于逐峰浏览。列标签包含采集维度、核种和 ppm，
因此两个氢轴仍能区分。切换方向后，每个峰保留相同 ID 和三个采集轴坐标。
谱图只显示属于当前切片的峰。

这些位置是人工观测，不是拟合峰中心。强度是最近采样网格点的有符号高度，
不是积分体积。峰编辑支持撤销、重做，并随 `.plotium` 项目保存。
相位变化保留峰身份与位置，更新有符号采样强度。

**Export peak table…** 导出 JSON，包含数据集 ID 和名称、采集身份、原始数据与
处理后体数据的规范 SHA-256 摘要、已应用的相位参数、轴身份、坐标、备注及
有符号高度。这些信息可在离开项目后识别来源和处理状态。

自动化通过 `nmr.peaks3d.list` 只读检查和导出 JSON，通过 `nmr.peaks3d`
增删改峰或定位。参数、稳定峰 ID 与采集轴顺序请参阅工具 schema。

MCP 通过 `plotium_peaks3d_inspect` 提供只读峰表；编辑操作使用
`plotium_plan` / `plotium_execute`，指定 `nmr.peaks3d`。
