Plotium 直接读取仪器文件和表格，无需任何转换步骤。完整的格式列表以及各导入器
读取的内容，见[支持的格式](/zh-cn/guides/supported-formats/)。

## 打开文件

把文件拖到 Plotium 窗口上，或使用 **Data** 页签的 **Import** 分组：*Open File…*、
*Open Folder…*（用于 Bruker TopSpin、Varian/Agilent VnmrJ 与 Waters MassLynx RAW 等采集目录）、
*Open Project…* 或 *Import Table…*。每个导入的数据集会出现在主侧栏中，
并自动放置到画板上。

文件选择器可以一次选择多个文件。打开文件夹时会递归导入其中所有 `.abf`、
`.spm`、`.pfc`、`.vms`、`.wiff`、结构化 CasaXPS `.txt` 和已识别的 `.raw`
数据包。配套文件（例如 `.wiff.scan`，或 `.raw` 目录中的内部文件）不会作为
独立数据集导入。

扩展名有歧义时，Plotium 按文件内容识别格式：`.txt` 只有在文件头表明是 CasaXPS 或
Rigaku XRD 时才按这些格式打开，否则进入[表格导入](#导入表格)。

## 查看导入进度

科学数据文件与采集目录会在后台加载，期间可以继续操作。一次导入多个数据集时，
它们会按原始发现顺序出现在画板上，不会切换当前页面或选择。状态栏显示当前文件及
成功、失败数量；错误可在诊断历史中查看。追加导入会排在当前批次之后。打开、关闭
或新建项目会取消旧项目尚未完成的导入。

NMR 导入包含默认处理，NUS 重建可能比读取文件耗时长得多。项目文件、表格预览、
ZIP 文件和手动补录采样表的导入使用各自的导入流程。

## 导入表格

对 CSV、TSV、带分隔符的 `.txt` 或 XLSX 文件，选择 **Import Table…**。表格也可以
直接从剪贴板粘贴：`Ctrl` + `Shift` + `V` 会把逗号、制表符或分号分隔的文本变成
新数据表。

无论从文件还是剪贴板导入表格，都会先打开 **Review table import** 对话框。它会
列出每列推断出的类型和单位、该列是否允许空单元格、前几行的预览，以及任何导入
诊断。选择 **Import table** 导入，或选择 **Cancel** 保持项目与最近文件列表不变。
含多个工作表的 XLSX 会额外提供 **Table** 选择器，可逐一预览工作簿中的各工作表；
一次 **Import table** 会把它们作为独立数据表全部导入。预览尚未处理完时，再选择
第二个表格文件会被拒绝；请先完成或取消当前预览。

导入的表格会以数据表的形式出现在画板上，旁边是一个放它的图的新页面。如何选择
图中显示哪些列，见[绘图与图表类型](/zh-cn/guides/plots-and-charts/)。

### 列类型如何确定

Plotium 会区分布尔、整数、小数、文本和空单元格。混合了不同类型、或取值含糊的列会
保留为文本而不会被丢弃。除非文件自带 Plotium 的类型信息（见下），只有毫不含糊的
取值才会自动获得类型：`true`/`false`、十进制整数、`YYYY-MM-DD` 日期，以及
`YYYY-MM-DDTHH:MM:SSZ` UTC 时间戳。依赖地区习惯的日期以及数值与文本混合的列仍
保留为文本，Plotium 不会猜测地区格式。

比表头短的行会用空单元格补齐（电子表格在部分列提前结束时会这样写），诊断会说明补了
几行。如果各列交替组成长度不同的 x/y 列对（例如每条曲线有自己 x 列的 Source
Data），诊断会列出这些列对。

### 误差棒列

要为自己的数据添加误差棒，请在 CSV 或 TSV 中紧跟某个 y 列之后放一列
`<y>_sigma`，存放每个点的不确定度（零或正数）；导入时 Plotium 会把它作为对称标准差
关联到该 y 列。

### Origin 导出的 CSV

从 Origin 导出的 CSV 开头有标签行（`Short Name`、`Long Name`、`Units`、
`Comments`）和一列行号。Plotium 用 Long Name 给列命名（没有时依次用 Comments、
Short Name），把单位加在括号里，把 Origin 的上标、下标和希腊字母写法转成正常字符
（`cm\+(-1)` 变成 cm⁻¹），把 Comments 保存在列上，并去掉行号列。如果 Origin 只导出了
一列、没有 x 值，就保留行号作为 x 列，并在诊断中给出警告。

Origin 项目文件（`.opj`）也在同一预览中打开；见
[Origin 项目](/zh-cn/guides/supported-formats/#origin-项目实验性)。

### Plotium 导出的表格

Plotium 导出 CSV 或 TSV 时，会在旁边写入一个配套的 `.plotium-schema.json` 文件；
复制 TSV 时（Windows 上）也会把同样的信息与纯文本一起放到剪贴板。重新打开其中
任一种，都能恢复原始的列类型、单位和误差棒关系。没有该配套信息时，Plotium 会在
导入时推断类型，并在检查对话框中标出含糊之处。

### Excel 工作簿

在 `.xlsx` 工作簿中，每个可见工作表都导入为独立数据表，Plotium 会把类型信息保存在
一个隐藏工作表中。Plotium 读取 Excel 为每个公式缓存的结果，但不会自行重新计算公式；
没有缓存值的公式单元格会以空导入，并列入诊断。导出的 XLSX 文件只包含确定值，
因此不依赖 Excel 重新计算。

## 补录缺失的 NMR 采样表

此选项适用于受支持的二维 Bruker NUS 或只采集了部分间接网格点的 JEOL 数据。
请准备原始采样表，以及含有足够网格与校准信息、可用于核对采样表的采集文件。

1. 选择 **File → Import NMR with Sampling Table…**（命令面板中也可搜索），
   再选择 Bruker `ser` 或 JEOL `.jdf` 文件。
2. 填写采样表来源或说明，以及原始间接轴的完整网格点数（包括未采样点）。
3. 填写 **Lanes per observation**：每个所列间接点采集的分量记录数。
   请按采集设置填写，不是填写采样表的点数。
4. 根据原表选择 **Zero-based**（从 0 开始）或 **One-based**（从 1 开始）。
   按采集顺序每行填写一个间接索引；每行代表该次观测的全部分量，并保留重复观测。
5. 点击 **Validate and import**。校验失败时，根据提示与采集记录核对。
   与已有采样表冲突、观测或分量数量不符、缺少网格或校准信息，都会阻止导入。

导入不会修改厂商文件。保存项目后，采样表及其来源会一并保留，重开无需原文件。
重复坐标可以导入，但目前不能进行 [NUS 重建](/zh-cn/guides/processing/#重建非均匀采样谱)。
脚本用法见 [CLI 声明格式](/zh-cn/reference/cli/#采样声明)。

## 使用 AI 客户端

也可以让连接到 Plotium 的 AI 客户端替你导入数据，例如：

> 导入 `/absolute/path/experiment.csv`。时间单位是 s，电流单位是 mA。画图之前先告诉我有哪些列。

AI 客户端可以导入你用完整路径指明的仪器文件和 CSV、TSV 或 XLSX 表格。单位只按你说明的来，
Plotium 不会猜。整次导入是一步 Undo；导入失败的文件不会在项目里留下任何内容。
画图之前请先核对它报告的列和单位。参见[权限、审阅与撤销](/zh-cn/ai/control-and-review/)。
