## 导出图形

从 **Figure** 页签的 **Output** 分组或 **File** 菜单导出——范围为当前页、全部页或页码区间。

| 格式 | 用途 |
| --- | --- |
| SVG | 矢量图，可在插图软件中继续编辑 |
| PDF | 矢量图，适合投稿 |
| PNG / TIFF / JPEG | 位图，DPI 可在 72–1200 间调节（默认 300） |

预设覆盖常见期刊图幅——例如 *Single column · 89 mm · 600 dpi ·
TIFF*——并且导出前的合规检查会按所选预设标出字号与线宽不达标之处。导出尺寸下
文字须不小于 7 pt，线条须不细于 0.5 pt；页面仍为某期刊尺寸预设时，改用该出版方
规定的下限（Nature 为文字 5 pt、线条 0.25 pt）。线宽检查涵盖数据曲线、等高线、坐标
轴线与刻度、柱状图描边、误差棒、符号描边、参考线和箭头；宽度为 0 表示不画线，不计入。页面含图片
时，还会报告导出尺寸下最低的有效 PPI、缺失或损坏的资源，以及带 ICC 配置文件或
高于 8 位采样的来源。图片达到 300 PPI 为通过，150–299 PPI 为警告，低于 150 PPI
为失败。位图输出为 8 位 RGB/RGBA，且不嵌入来源 ICC 配置文件；对颜色要求严格的
工作应在最终出版流程中另行核对。

所有图形格式都会包含嵌入图片，并应用裁剪、旋转、透明度、适配、插值、Panel
裁切和 z 顺序。SVG 会嵌入图片像素，不会链接本机路径，SVG、PDF 和位图输出会把[矢量图片](/zh-cn/guides/images/#矢量图片)保留为路径；PDF 与位图导出使用同一份
页面效果。来源缺失或损坏时，导出默认停止。只有在需要带标签的审阅稿时，才勾选
**Export with missing-image placeholders**。

### 裁去页面空白

在“导出”对话框中启用 **Trim page to visible content（将页面裁至可见内容）**，
可移除最终渲染内容四周的页面空白。PNG、JPEG、TIFF、SVG 和 PDF 均支持此
选项，Plotium 会记住该选择并用于后续导出。

裁边在目标宽度预设确定页面物理缩放后执行，只改变页面边界，不会再次放大或
适配内容。因此使用期刊或分栏预设时，最终页面的物理宽度可能小于预设宽度。
所有受支持的格式均保留 1 pt 物理安全边；位图会按输出 DPI 向上取整至完整像素。
空页面保持原尺寸。

## 复制图形

*Copy figure*（复制图形，`Ctrl` + `C`，也可在导出菜单、命令面板或图框
右键菜单中触发）把选中的图框——未选中时为活动画布——连同图片直接复制到
剪贴板，无需先导出。在 Windows 上会同时发布 PNG、DIB、SVG 和 EMF，接收应用
从中选择其支持的格式。

## 导出数值数据

选中数据集后，可从 File 菜单、Data Ribbon 选项卡或命令面板选择
**导出数据…**。对话框只显示当前数据集实际存在的内容，并提供
**保存 CSV…**、**保存 TSV…**、**保存 XLSX…**和**复制 TSV**。空单元格保持为空；
`NaN`、`+Inf` 和 `-Inf` 会写成这些字面标记，因为它们是真实取值而非空白。

处理后的 NMR 数据可选择 Real、Imaginary 或 Magnitude 强度。真实 2D 与
伪 2D 均支持 **Matrix** 和 **Long**：Matrix 首行是 F2/ppm，首列是
F1/ppm 或伪 2D 的系列轴；Long 每行一个观测值，真实 2D 使用
`f1_ppm,f2_ppm,intensity`，伪 2D 则使用带名称和单位的系列轴、`ppm` 与
`intensity`。大型导出在后台生成。

对 XPS，**Processed data** 包含原生轴、结合能轴、处理轴与拟合轴，原始/处理后 CPS，
所选背景模型、拟合窗口与锚点，扣背景强度、拟合包络、残差和每个组件；
**Curve-fit parameters** 还包含标准误、近似 95% 区间、最大相关性、RMSE 与可选
Bootstrap 分位数。CasaXPS 结果始终标为 `Imported (CasaXPS)`，不会伪装成 Plotium
拟合。

从数据表导出的 CSV 或 TSV 会附带一个配套的 `.plotium-schema.json` 文件，XLSX 导出
则把同样的信息保存在隐藏工作表中。可见的列在 Excel、Origin 或 Prism 中正常打开，
而配套信息让 Plotium 日后能连同列类型、单位和误差棒一起重新打开该表。导出的 XLSX
文件只包含确定值，没有需要重新计算的公式。

## 使用 AI 客户端

也可以让连接到 Plotium 的 AI 客户端替你完成，例如：

> 把这张 180 × 90 mm 的画布导出到 /Users/me/figures/figure.svg，同时导出对应的 PDF 和 300 DPI 的 PNG。不要覆盖已有文件。

写文件前 Plotium 会请你确认具体路径；覆盖已有文件还要单独勾选。导出不会保存项目。
参见[权限、审阅与撤销](/zh-cn/ai/control-and-review/)。
