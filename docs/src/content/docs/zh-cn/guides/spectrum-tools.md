有两个工具作用于多条谱而非单条谱：**谱运算**用已有的曲线生成一个新数据集，
**谱图对齐**平移整个系列使参考峰对齐。二者都可从 1D 谱的分析面板、功能区的
**Process › Transform** 或命令面板（<kbd>Ctrl</kbd>+<kbd>K</kbd>）打开。

## 谱运算

**谱运算**把 1D NMR 谱、XRD 图谱、XPS 区域或已绘制的表格曲线组合成一个新的
独立数据集——源数据集不会被修改。

提供五种运算：

- **A + k·B** 与 **A − k·B**——加上或减去第二个谱，并乘以系数
  *k*（默认 1）。微调 *k* 即可在扣除中压平溶剂峰、平衡差谱，或扣除空池、基底
  的图谱。
- **A × k**——谱乘以常数。
- **A + c**——加一个常数偏移。
- **Average**——合并 XRD 图谱、XPS 区域或表格曲线的重复扫描。结果使用 A 的轴，
  每个点只平均覆盖该点的曲线。

操作数必须是同类数据集，且 x 范围必须有重叠。XRD 和 XPS 使用屏幕上处理后的曲线：
XPS 取当前区域，表格取第一条已绘制的曲线。XRD 图谱不能声明不同的波长，XPS 区域
必须使用同一能量标度，表格的轴和数值单位必须相同，含空格的表格行会被跳过。XRD
结果中的负值会设为零，状态栏会提示改动的点数。

两个 NMR 谱必须是同一核种；核种不同时会拒绝并在对话框中显示原因。
若两条曲线的轴不一致（点数或范围不同），第二条会线性插值到第一
条的轴上，重叠区间之外按零处理——对话框会提示这一情况。

结果是一个同类的独立数据集，放置在自己的页面上，并以表达式命名（例如
`A − 0.9·B`）。它与该类的其他数据集行为一致——NMR 谱的峰、积分、区域与导出
均可使用——且创建过程是单个可撤销步骤。

## 谱图对齐

**谱图对齐**把一系列 1D 谱平移，使共同的参考峰落在同一化学位移位置——
适用于反应监测、滴定等参考峰在多次采集间漂移的系列实验。

对话框作用于数据列表中的多选（少于两个被选中时作用于全部数据集）：

- 选择一个 **ppm 区间**；默认取当前活动谱的可见范围。每条谱在区间内
  最高的显著峰即其参考峰。
- 选择**对齐目标**：参考谱自身的峰位置（活动数据集为参考谱），或手动
  输入一个 ppm 值。
- 预览表逐一列出数据集、找到的峰位和将要应用的平移量。区间内没有显著
  峰、核种不同或非 1D 类型的数据集会被跳过，并显示原因。

平移通过每条谱的**参考**步骤写入——与单谱化学位移定标使用同一机制——
因此之后仍可在管线中查看和编辑。整个对齐操作是跨所有数据集的单个可撤销
步骤。
