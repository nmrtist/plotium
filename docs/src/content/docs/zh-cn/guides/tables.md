表格在 Plotium 中是一等数据集：承载导入的表格数据、区域工具提取的数值，
以及拟合结果。

## 编辑

表格在画板上显示为工作表框，预览前 24 行和前 8 列；框的标题显示完整的表格规模。

双击画板上的表格即可打开可编辑的工作表。工作表是电子表格式的网格：带行号、
列宽可拖拽，表头显示列名并在下方标注单位和类型。空单元格显示为弱化的短横线，
`NaN` 与无穷值也以弱化样式显示。小数最多显示六位有效数字，极大或极小的值用科学
计数法，与画板上的显示一致；编辑和复制时始终使用完整数值。网格只绘制当前可见的
行窗口，超大表格依然流畅。

工作表停靠在画板下方、两侧边栏之间，画板会相应变矮，因此不会遮住任何页面。拖动
工作表的上边缘可调整高度，Plotium 会在会话之间记住这个高度。标题栏显示表名、状态
（可编辑、只读并与来源同步，或需要刷新）以及表格规模。用左侧的箭头可把工作表折叠
成只剩标题栏，用右侧按钮可最大化并还原，用 × 关闭。在不同表格之间切换时，每张表
都会保留自己的滚动位置和选中格。宽表可在工作表内横向滚动，方向键会把选中格带入视野。

**New Empty Data Table（新建空数据表）** 会在工作表中打开一张空表并选中第一格，可以
直接输入；撤销一次即可删除这张表。会自带画布的结果（例如膜片钳的 IV 表和窗口统计表）
不会自动打开工作表，需要时在数据列表中双击该表即可打开。导入的打开方式见
[界面术语](/zh-cn/reference/ui-overview/)。

单击选中单元格，用方向键移动；双击、按 **Enter** 或 **F2**、或直接输入即可开始
编辑。**Enter** 提交并下移，**Tab** 提交并右移，**Esc** 取消。输入不合法时编辑框
保持打开并以红色描边提示，悬停可查看原因。点击行号选中整行；**Ctrl+C** 复制当前
单元格或整行。网格下方一行显示当前选中位置。

只有点击单元格、行号或列标题后，工作表才接管键盘，此时选中格的描边由灰色变为强调色。
接管期间，**Delete** 或 **Backspace** 清空选中的单元格（列不允许空值时会说明原因），
**Ctrl+V** 用剪贴板中的单个值开始编辑选中的单元格；暂不支持一次粘贴多个单元格。
**Ctrl+Shift+V** 仍然粘贴为新表格。点击画板或按 **Esc** 即可把按键交还给画板和工具。

单元格编辑尚未完成时，AI 助手可以读取已提交的数据，但需要等待你处理草稿后才能修改。
点击 **Apply（应用）** 提交输入，或 **Discard（放弃）** 取消。如果编辑期间表格发生
变化或不再可用，工作表会保留输入并说明冲突。可先用 **Copy draft（复制草稿）**
保留文本，再放弃草稿并重新打开单元格。
离开当前项目前，也需要先完成或放弃编辑。

每次编辑都可撤销；撤销和重做会在表格的编辑历史中前后移动，而不是每次都替换整张
表。文本、布尔、日期和空单元格的编辑方式与数字完全相同。

## 转换与刷新表格

右键单击列头，可围绕该列重塑表格。菜单提供 **Rename（重命名）**、
**Sort ascending（升序）** 和 **Sort descending（降序）**、**Keep only this
column（只保留该列）**、**Filter out empty rows（过滤空值行）**、**Duplicate as
computed column（复制为计算列）** 和 **Count rows per value（按值计数）**；浮点列
还会增加 **Mark non-finite as missing（把非有限值标为缺失）**，以及当该列带有可
换算单位时的 **Convert unit（换算单位）** 子菜单。表格含多列同一类型时，可用
**Unpivot matching columns** 把它们堆叠成名称/取值行，文本列可用 **Pivot using
these names** 把其取值变成新列名。工作表工具栏中的 **Combine** 菜单可与项目中的
另一张表执行合并或联接。每次转换都会生成一张新表，原表保持不变。工作表会切换到新表，
不会新建画布；标题栏中的 **Derived from（来源）** 可返回原表。

转换在后台运行：工作表会显示耗时和 **Cancel（取消）** 按钮，取消或失败的转换不会
替换原表。由另一张表生成的表会获得 **Refresh（刷新）** 操作——它会重跑生成该表的
步骤，再把你之后的单元格编辑重新应用到结果上。如果来源数据发生变化、导致被编辑
的行无法再匹配，或某列的类型或单位不再吻合，刷新会停止并报告冲突，而不会猜测哪
一行对应哪一行。

这些转换也可以作为批处理任务无人值守地运行——参见
[自动化](/zh-cn/guides/automation/)和[命令行](/zh-cn/reference/cli/)。

## 导出表格

**导出数据…**可以把完整表格导出为 CSV、TSV、XLSX 或剪贴板 TSV。空单元格保持为
空；`NaN`、`+Inf` 和 `-Inf` 会写成这些字面标记，因为它们是真实取值而非空白。CSV、
TSV 和 XLSX 会把表格的列类型、单位和误差棒关系与数据一起携带（在 Windows 上剪贴板 TSV 也会），因此再次导入时不会
丢失这些信息；见 [Plotium 文件](/zh-cn/reference/file-formats/#表格-schema-配套文件)。导出选项见
[导出数值数据](/zh-cn/guides/exporting/#导出数值数据)。

## 分析表格

- 要把表格的列画成图、选择图表类型，见[绘图与图表类型](/zh-cn/guides/plots-and-charts/)，
  其中也介绍了如何添加[误差棒](/zh-cn/guides/plots-and-charts/#误差棒)。
- 需要用数学模型拟合 x-y 数值时，在**分析**选项卡的**曲线拟合**组中选择
  **拟合曲线**；见[曲线拟合](/zh-cn/guides/curve-fitting/)。拟合曲线及其结果会
  保留在表格中。每次完成拟合都会记录它使用了哪些行、排除了哪些行以及排除原因，
  因此后续编辑表格不会悄悄改变该结果所依据的观测点。使用**导出数据…**并选择
  **曲线拟合参数**，可导出参数、诊断、协方差以及逐点预测和残差，导出中会列出
  纳入和排除的行。
- 要比较分组、检验相关性、检查正态性或运行方差分析，在 **Analyze（分析）**
  标签中选择 **Statistics（统计）**；见[统计分析](/zh-cn/guides/statistics/)。
- 要分解所绘曲线中相互重叠的谱峰，请改用**谱峰拟合**；见
  [分析工具一览](/zh-cn/guides/choosing-a-tool/)。

## 使用 AI 客户端

也可以让连接到 Plotium 的 AI 客户端替你修改表格数据，例如：

> 只改这一个源单元格，告诉我哪些派生表过期了，然后刷新这张表。保留我的颜色、坐标轴范围和排版。

> 从这张表生成一张新表：加一列等于 current × 2，只保留 time 不为 0 的行，并按 time 降序排列。

修改单元格和刷新派生表是两步独立的 Undo；图的样式不变。派生表是一张新表，
不会改动它的来源。使用前请先检查刷新后的数值。参见[权限、审阅与撤销](/zh-cn/ai/control-and-review/)。
