每个导入的数据集都会得到一个带图的页面。谱图和其他仪器数据导入完成后图就已经画好。
普通表格还需要多一步：告诉 Plotium 要画哪几列。

## 由表格作图

[导入 CSV、TSV 或 XLSX 表格](/zh-cn/guides/importing-data/#导入表格)时，Plotium 会在工作表中打开它，并为它新建一个页面，
页面上是一张空的折线图。要把数据画出来：

1. 在页面上选中这张图。
2. 在对象检查器中展开 **Data → Curve columns**。
3. 选择 **X** 列和 **Y** 列。列表中只列出数值列；Plotium 初始以第一个数值列作 X、
   第二个数值列作 Y。
4. 如需误差棒，可再选择 **Y error** 列（见[误差棒](#误差棒)）。
5. 点击 **Apply curve binding**。

随后 Plotium 会报告画出了多少行，以及有多少行因数值缺失或不是有限值而未画出。

要在同一张图里再画几列，展开 **Data → Add curve**，选择源表格及其 **X**、**Y** 和
可选的 **Y error** 列，选 **Line** 或 **Scatter**，再点击 **Append curve**。源表格
可以是项目中的另一张表，因此派生表可以加入它所来源的那张图。单位无法换算到该图
现有单位的曲线会被拒绝。

之后要更换某条曲线的数据列，再次展开 **Curve columns**，选择新的列并点击
**Apply curve binding**。两张图可以用不同的列绘制同一张表；修改其中一张不会影响另一张。

Plotium 自己生成的表格（例如区域积分或拟合结果）已经知道哪一列是 x、哪些是数值列，
会直接画出。如果这样的图画有多条默认曲线，**Curve columns** 会先提供
**Expand default curves**：选择保留身份的那条曲线，之后就能分别修改每条曲线的数据列。

## 图表类型

选中由表格生成的图，在对象检查器的**图表类型**画廊中选择。Ribbon 的 **Figure**
页签中的 **Chart** 可直接跳转：它会选中表格对应的图并打开检查器。

选图表就是选它回答的问题：沿轴跟踪数值用 **Line**；跨类别比较数量用
**Bar** 或 **Grouped bars**；看单列数值的分布用 **Histogram**；一眼比较
多列的分布用 **Box** 或 **Violin**；展示整体中的占比用 **Pie**；一次看
整个数值矩阵用 **Heatmap** 或 **Surface 3D**。

- **Line（散点/折线）**——每列一组散点，按 x 轴排布；已有拟合时叠加拟合曲线。
- **Bar（柱状图）**——所选单列在数值 x 轴上绘制为填充柱。
- **Grouped bars（分组柱）**——每行一组、组内各列并排；勾选 **Stacked**
  改为堆叠（正值向上、负值向下堆叠）。
- **Histogram（直方图）**——所选单列的数值分布。默认按
  Freedman–Diaconis 规则自动分箱；取消勾选 **Auto bins** 后可在 **Bins** 中
  指定 1 到 512 的固定箱数。取消勾选时沿用自动规则刚算出的箱数，因此直方图
  不会随之变样。
- **Box（箱线图）**——每列一箱：中位数、四分位箱体、1.5 × IQR 须线，
  以及逐个绘制的离群点。
- **Violin（小提琴图）**——每列一个核密度轮廓，内嵌四分位条
  （每列至少需要两个不同数值；退化列回退为原始散点）。
- **Heatmap（热图）**——整张表作为色图矩阵，行自上而下排列；
  在检查器中选择色图。x 列单调增加或减少时显示为数值轴；列名只有这样的数字不同时
  （如 `300 K`、`t=10 min`、`scan 12`）也显示为数值轴，步长不均匀时保留真实间距。
  其他情况仍按行或列逐格排列。打开 **Transpose** 后，
  x 列横向排列、各列纵向排列，就是 2θ 对时间的原位图。要设定颜色覆盖的数值范围，
  见[热图颜色范围](/zh-cn/guides/heatmap-range/)。
- **Pie（饼图）**——所选单列的每一行为一个扇区，并标注百分比。
  负值与缺失行不参与。
- **Surface 3D（3D 曲面）**——把表格视为高度场，以固定正交视角绘制；
  可在检查器中调整方位角/仰角与色图。

分组柱、箱线、小提琴、热图与 3D 曲面一次使用全部列；柱状图、直方图和
饼图读取画廊旁选中的单列。所有图表在屏幕显示与 SVG/PDF/EMF 导出中
完全一致。

**Chart › Advanced** 中的 **Purpose** 和 **Claim** 记录这张图要表达什么（例如趋势或
组间比较）以及它要支持的那一句结论。它们不会改变图形。AI 客户端检查图形时会拿图表
与它们对照，提出更合适的图形形式，但不会自行切换。

## 误差棒

误差棒来自一列——它保存另一列的不确定度。在 **Curve columns** 或 **Add curve** 中
把它选为 **Y error**。Plotium 会检查数值列与其不确定度的单位是否兼容。折线图、柱状图和
未堆叠分组柱会把它们绘制为纵向误差棒，并扩展 y 轴范围以保证误差棒完整可见。在对象检查器的
**Line** 中，**Error bars show** 记录误差棒表示 SD、SEM 还是 95% CI，**Replicates (n)**
记录每个值汇总了多少次测量；AI 客户端会向你询问这两项。

Plotium 分析工具生成的表格已经带有不确定度，导入的表格则会带上其文件所描述的关系——
对称 ±σ、分开的上下误差，或带置信水平的置信区间。要在自己编写的 CSV 或 TSV 中标出不确定度列，
见[误差棒列](/zh-cn/guides/importing-data/#误差棒列)。

## 带阴影的柱子

通过 **Curve columns** 或 **Add curve** 添加的柱状曲线可以加阴影：在对象检查器的 **Line › Advanced** 中，把
**Bar hatch** 设为 **Forward diagonal**、**Backward diagonal** 或 **Crosshatch**。斜线使用
**Bar outline color** 的颜色，缩放图时线距保持不变。要做空心柱，把曲线颜色设为白色；要让某一根柱子样式
不同，把它放进单独的曲线。阴影会显示在图例中，并以真实矢量线条出现在所有导出格式里。

图表库的 **Bar** 和 **Grouped bars** 在 **Chart › Advanced** 中有一个 **Bar hatch**，作用于全部柱子，斜线使用各柱颜色的深色。

## 一张图中的多个数据集

一个图框可以同时显示多个 1D 数据集——可叠加显示，也可以按可调的垂直间距与 3D 错切
堆叠。2D 数据集则以颜色叠加方式组合。在对象检查器 **Data** 中使用 **Add series…**
可以把另一个数据集加入所选的图。

如果想把相关的几张图上下排列、共用一条 x 轴，请使用
[共享 x 轴堆叠](/zh-cn/guides/multi-panel-figures/#共享-x-轴堆叠)。

## 序列数据的瀑布图

每列一条谱的表格（例如一组原位扫描）可以堆叠成瀑布图。图表类型为 **Line**
时，在对象检查器的 **Stack** 分组中把 **Mode** 设为 **Offset**，再调整 **Vertical spacing**
和 **3D shear**。多个数据集组成的堆叠也可以使用下面这些选项。

- **Gradient**：用色图按序列给各条谱渐变配色。
- **Fill under traces**（在 **Advanced** 中）：每条谱遮住它后面的谱。
- **Side scale**（在 **Advanced** 中）：在右侧标注各条谱基线对应的序列值，代替图例。

序列来自谱的名称：名称只有数字不同时（如 `300 K`、`t=10 min`）读取其中的数字，
刻度标题也取自名称；其他名称按谱的顺序排列。把 **Type** 切换为 **Heatmap**，
就能用同一张表显示热图。

## 对齐曲线

若要沿 x 轴对齐线条序列，请选中图形，然后在 **Analyze** 页签的 **Overlay** 组中
选择 **Align Traces…**。当图中至少有两条可见线条序列使用相同的 x 轴单位时，
此命令才可用。也可以从对象检查器的 **Data** 中选择 **Align traces…**，打开
同一个对话框。

选择参考序列后，可用 **Trace start**（第一个有限绘制样本）对齐，也可在指定的
x 区间内按峰对齐。按峰对齐时，**Positive** 查找向上的峰，**Negative** 查找
向下的峰，**Magnitude** 比较两者的突出度。选择 **Apply** 前，请检查
**Anchor**、**Delta** 和 **Result** 列。隐藏、不兼容或没有可用对齐位置的序列会
列为 **Skipped**，并保持不变。

对齐会保留图形当前的缩放范围。若要手动调整一条线，可在 **Data** 中编辑其
**X shift**。自动和手动位移都是可撤销的图形设置，不会改变来源数据或数据导出。

## 使用 AI 客户端

也可以让连接到 Plotium 的 AI 客户端替你完成，例如：

> 导入 /Users/me/data/experiment.csv。用 time 作 X、current 作 Y，单位分别是 s 和 mA。建一张可编辑的折线图，先给我看预览。

> 删除这条重复的备注和这条曲线，但保留另一条同名的曲线。删除前先告诉我会删掉什么。

建图之前，AI 会先和你确认这张图要表达什么，并把回答记为图的 **Purpose** 和 **Claim**。
单位只按你说明的来；只删除你指定的内容，源数据保留；每次修改都是一步 Undo。
同意之前请先看预览。参见[权限、审阅与撤销](/zh-cn/ai/control-and-review/)。
