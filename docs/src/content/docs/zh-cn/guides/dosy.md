---
title: DOSY 扩散分析
description: 在 Plotium 中确认扩散编码、拟合区域衰减曲线并构建 DOSY 图。
---

DOSY 分析将各采集增量中的谱信号衰减与扩散编码联系起来，扩散编码以 b 值表示。
Plotium 的区域曲线、逐列拟合和反拉普拉斯变换（ILT）图使用同一组解析后的 b 值。

先选择需要的结果：

| 目标 | 操作路径 | 结果 |
| --- | --- | --- |
| 测量选定峰的扩散系数 | 提取区域曲线，再用 **Diffusion (b values)** 拟合 | 每条拟合曲线的扩散系数 D 及拟合诊断 |
| 查看全谱的扩散行为 | **Build DOSY map** | 每个通过筛选的化学位移列对应一个拟合 D 值 |
| 估计各化学位移处的扩散系数分布 | **Build ILT DOSY map** | 指定 D 网格上的非负分布 |

## 准备谱图堆叠

1. 导入伪 2D 数据集并完成谱图处理。构图需要以 ppm 标定的频域谱堆叠。
2. 选中数据集，选择 **Analyze → DOSY…**。即使采集参数缺失，谱图堆叠仍可打开
   专用的 **DOSY** 任务卡片。
3. 检查卡片中显示的输入来源和 b 值范围。在拟合或构图前，补齐缺失输入并完成确认。

在画布上显示、比较和对齐增量的方法见[伪 2D 分析](/zh-cn/guides/pseudo-2d/)。
画布上的轨迹位移仅影响图形，不会校正 DOSY 或 ILT 图所用的处理后谱图。

## 确认扩散分析输入

Plotium 能验证采集证据时，会自动提供采集建议。否则，选择 **Sequence model**
或 **Direct b values**，再点击 **Confirm and apply analysis input**。
输入和处理后的堆叠有效前，构建按钮保持禁用。

### 序列模型

支持的矩形梯度 **PGSE / STE** 或 **JEOL BPP-DSTE** 实验可以使用此模式。
确认实际脉冲序列，并按以下单位填写参数：

| 量 | 单位或约定 |
| --- | --- |
| 旋磁比 γ | rad/(s·T) |
| 时间 δ、Δ、τ / τ₁、τ₂ | 秒 |
| 导入的梯度强度 | T/m；`0.02–0.28 T/m` 即 `20–280 mT/m` |
| JEOL BPP-DSTE 的 δ | 总编码宽度；每个梯度瓣持续 δ/2 |

空白间隔保持缺失；间隔为零时必须明确输入零。序列模式需要导入的梯度轴，单位为 T/m。
其他序列或梯度形状请提供按实际实验计算的 b 值。

### 直接输入 b 值

选择 **Direct b values** 粘贴数值，或用 **Import b values…** 导入包含数值的文本、
CSV 或 TSV 文件。用空格、逗号、分号或换行分隔数值，不要包含表头或其他列。

- 每个采集增量提供一个有限、非负的 b 值，且至少包含三个不同值。
- 选择所提供数值的单位：`s/m²`、`s/cm²` 或 `s/mm²`。Plotium 会转换为 `s/m²` 分析。
- 按采集顺序输入。画布上的轨迹排序或隐藏操作不会改变 b 值与增量的对应关系。

直接输入 b 值不要求梯度元数据。**Use acquisition suggestion** 会清除已保存的手动
覆盖设置；没有可验证的采集建议时，需要重新提供有效输入。

## 拟合选定峰区

1. 显示 **Stack**，选择 **Analyze → Draw Regions**，在感兴趣的峰上绘制区域。
2. 在 Regions 任务卡片中选择 **View extracted curves**。每个区域生成一个点系列，
   横轴为 b；有梯度数据时会保留辅助梯度列。
3. 在 **Curve Fit** 中确认选择了 **Diffusion (b values)**，再点击 **Run Fit**。
   模型为 `I = I₀ exp(−Db)`，D 的单位为 `m²/s`。
4. 检查拟合曲线、参数不确定度及诊断。通过 **View data** 查看同步表格，或用
   **Back to regions** 返回并调整源区域。

区域曲线使用定相后带符号的实部强度；全谱图使用各谱列的模值，因此两条分析路径的结果
不一定相同。求解器、权重和诊断选项见[曲线拟合](/zh-cn/guides/curve-fitting/)。

## 构建全谱扩散图

选择 **Build DOSY map** 进行逐列单指数拟合，或选择 **Build ILT DOSY map**
估计扩散分布。构图在后台运行；**Cancel DOSY computation** 可丢弃正在进行的构建。
同一数据集的当前构图完成或取消前，不能启动另一次构图。

在 **Show** 中选择 **Stack** 或 **DOSY map**。选中的图不可用时，Plotium
显示堆叠图。扩散图的坐标轴为化学位移和扩散系数 D（`m²/s`）。

### 选择方法

逐列方法为每个通过筛选的谱列赋予一个 D 值，可用于查看全谱中的单指数衰减行为。
弱信号列和没有合格拟合的列会被略去；缺失图形特征不表示测得的扩散系数为零。

ILT 在每个谱列估计 D 的非负分布，可用于考察某个化学位移处是否存在多个扩散贡献。
解读分布时，应结合区域衰减拟合，以及结果对下列设置的敏感程度。

### ILT 设置

构图前，在 **DOSY** 卡片中展开 **ILT settings**：

| 设置 | 含义 |
| --- | --- |
| λ | 分布幅度惩罚项的权重。值越大，对幅度的惩罚越强；值越小，测得的衰减对结果的影响越大。允许范围为 `0.000001` 到 `1000`。 |
| D min / D max | 扩散网格的正数下限和上限，单位为 `m²/s`。范围应覆盖要考察的扩散系数。 |
| Grid points | 对数等间距的 D 网格点数，范围为 16 到 512。增加点数可更细致地采样分布，也会增加计算量。 |

网格更密本身不能证明两个组分已被分辨。调整 λ 和 D 范围，检查特征是否仍然存在。
若信号集中在网格边界，应先检查范围再解读结果。

下一次构图优先使用为该数据集明确输入的设置，其次使用上一次 ILT 结果的设置。
都没有时，λ 取 **Preferences → Processing** 的默认值（`0.01`），网格取内置默认值。

## 修改输入与保存结果

手动分析输入不会改变导入的采集事实。修改可撤销，会取消正在进行的构图，并使旧图和
关联区域拟合失效。冻结表格保留当时捕获的输入快照。修改谱图处理也会取消构建并使图
失效。完成修改后，请重新构建结果。

使用 **Map method → Per-column / ILT** 可切换已保存的结果，无需重新计算。
构建对应图后，该方法即可选择。

`.plotium` 项目会保存两种图、各自的分析输入和 ILT 设置，以及显示选择。重新打开项目
通常无需重算即可恢复结果。如果保存的图与重建数据不再匹配，Plotium 会继续显示该图，
并在 **DOSY** 卡片和操作历史中给出警告。保存的图无法读回时显示堆叠图。
重新构建即可清除警告。

## 编码核验与可复现性

对已识别的 JEOL Delta 矩形梯度 BPP-DSTE 程序，Plotium 核对完整脉冲段、参数单位和
时间关系，计算 `C = Δ − 2δ/3 − (τ₁ + τ₂)/2`、`b = (γδg)² C`，其中 δ 为总编码宽度。
厂商程序的 `st_coef` 会被保留为证据，并在允许舍入误差的范围内交叉校验。证据一致时
自动接受；程序修改或证据不完整时，需要明确确认模型或直接提供 b 值。

导入 JEOL JDF 时间参数时，Plotium 会合并记录的数值缩放与 SI 前缀，并统一转换为秒。
例如，`0.0035 s`、`3.5 ms` 和 `3500 µs` 得到的 δ 均为 `0.0035` 秒。

结果会记录分析输入、模型和规则版本、采集证据、最终 b 值及数据指纹。输入解析优先采用
显式调用输入，其次为选中结果记录的输入、已保存设置，最后为已验证的采集建议。
这样可保留结果实际使用的输入，避免后来的默认值被静默替换进来。
