## 数据浏览器

把主侧栏切换到 **Data**，即可查看项目中全部内容的可搜索树。导入的数据
集是根节点；切片、投影、谱运算结果、区域表、谱峰拟合表和多重峰表显示在
来源数据集的 **Derived data** 下。展开 **Analysis** 可查看单个峰、积分、
区域、谱峰拟合、多重峰和已拟合的表列。

链接图标表示结果有多个来源——例如由两条谱共同生成的表。每个来源下的
条目都是同一个数据集，并非副本：选择、高亮、重命名和打开数据表会保持
同步。悬停图标可查看全部来源，也可在右键菜单中使用 **Reveal sources**。

搜索不区分大小写，并保留结果的完整祖先路径；清空搜索后会恢复此前的展开
状态。

多个搜索词可分别匹配数据集名称、实验名称、标签、数据类型、维度、来源和科学摘要
（例如 `600.0 MHz`）。
例如，`hnco 3d batch-12` 可分别匹配实验名称、采集维度和来源文件夹。将鼠标
悬停在数据行上可查看来源详情。单击标签即可筛选，再单击 × 可移除筛选条件。

在 **Canvas** 中，单击画布卡片上数据摘要旁的铅笔图标。如果画布包含多个
数据集，请先选择要编辑的一个。在 **Data** 中，可右击数据集并选择
**Edit experiment and tags…**，也可选中多个数据集，通过列表上方的按钮批量编辑。
可以自由输入显示名称，也可选用常见的 NMR 实验名称。编辑单个数据集时，窗口会
单独显示导入原名。**Use imported names** 会清除自定义名称，恢复导入值。
实验名称和标签只用于标识和整理，不会改变处理或归属。
可添加新标签，也可从 **Project tags** 选择已有标签。多选时，标签旁的计数
显示有多少个所选数据集带有该标签。移除标签时会保留其他标签。这些编辑可撤销
和重做，并随项目保存。

使用 **Locate plot** 可直接定位数据集所对应的绘图系列，包括叠加图中的系列。
若有多个位置，请在 **Plot destinations** 窗口中选择目的地，即使筛选条件隐藏了
数据行也可以选择。隐藏的系列会有标记；单击 **Reveal** 可显示该系列。定位时会
保留筛选条件，并短暂高亮可见的目标系列；定位热图时则会描出图框。

## 选择与打开

单击数据集或引用可将其选中。`Shift` + 单击选择从上一个主项目到当前项目的
连续区间；`Ctrl` + 单击（macOS 上为 `Cmd`）添加或移除单个项目；同时按住
两者则在不清除现有选择的情况下追加一个区间。Canvas 与 Layers 列表使用
相同的扩展选择方式。多选正是在一个图中堆叠多条谱、或把处理模板一次应用
到多个数据集的方式。

列表处于活动状态时，可用 `↑` / `↓` 或 `Home` / `End` 移动选择，按住
`Shift` 扩展选择，按 `Space` 添加或移除主项目。`Ctrl` + `A` 全选数据集，
`Ctrl` + `Shift` + `A` 清空选择。双击数据集打开其数据表。单击分析项会聚焦
其所属数据集，双击则
跳转到相应图和分析工具。

要删除数据集，可在其右键菜单或 **Edit** 菜单中选择 **Delete Dataset**，或在
数据列表中选中后按 `Delete` 或 `Backspace`。仍被图、派生数据集或分析报告使用的数据集不会被删除；状态栏会
指出使用它的内容，先删除这些内容即可。删除可以撤销。

用很旧版本的 Plotium 保存的项目可能把部分派生结果显示为顶层数据集；它们
仍完全可用。

在 **Canvas** 中，画布标题下方概括了直接绘制在其中的数据集，也包括隐藏的
系列。同一数据集使用多次仍只计一次。将鼠标悬停在标题上可查看完整组成。

## 画板视野

在 **Canvas** 模式下，侧栏下方是已命名的 **Board views**——保存下来的
画板视野，可一键返回。浏览数据时会隐藏。

## 保存项目

`Ctrl` + `S` 打开项目保存选项。`.plotium` 项目文件保存整个会话——导入的
数据、处理、分析结果和排版——重新打开时恢复原状，也可以作为单个文件
分享。文件内容见 [Plotium 文件](/zh-cn/reference/file-formats/)。

保存会在后台运行。如果保存过程中继续编辑，完成的文件包含保存开始时捕获的
版本，而 Plotium 会让后来发生的编辑继续保持“未保存”状态。

编辑暂停后，Plotium 还会写入内部崩溃恢复检查点；连续工作时最长恢复间隔为
一分钟。只有文档相对上一个检查点发生变化时才会重新写入；成功保存最新版本
或正常退出后，检查点会被清除。

**Preferences → General → Project backup copies** 会在项目旁以隐藏文件
保留指定数量的完整历史保存，误覆盖后可以恢复。

**File → New Project**、**Close Project**、打开其他项目和退出 Plotium 在
当前项目有未保存修改时，都使用同一个 **Save / Discard / Cancel** 确认流程。

在欢迎页可打开数据、导入表格或打开已保存的项目。**Close Project** 会返回欢迎页。

## 查找画布和图片

**Canvas** 与 **Data** 页签共用搜索词、标签和导入批次筛选。画布搜索还匹配画布名和
图片图层名，包括没有绘制数据集的画布。标签或数据导入批次筛选只保留含有匹配数据集的
画布；清除这些筛选即可重新显示纯图片页面。

选择 **Compact rows** 可使用纯文字画布列表。Layers 在列表下方有独立滚动区域。
选择搜索结果会定位已有画布，不创建副本；Shift 范围选择和键盘导航只经过筛选后的行。
