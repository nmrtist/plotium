## 画板

图形放置在按页面组织的无限画板上。拖动图框时会自动吸附到页面网格、
页边距以及相邻图框的边缘；吸附可在 **Arrange** 页签中关闭。**Arrange** 页签还提供
对齐（选中两个及以上图框）、水平 / 垂直分布（三个及以上）、层叠顺序，
以及 *Tidy up frames*（一键整理）命令。

在画板空白处拖动可框选页面和工作表图框。按住 `Shift` 可追加框内图框，按住
`Ctrl`（macOS 上为 `Cmd`）可切换框内图框。拖动任一所选图框的标题栏会移动
整个选择，并可作为一步撤销。在 Canvas 列表中，`Shift` + 单击选择连续区间，
`Ctrl` + 单击添加或移除单个画布。`Ctrl` + `A` 会根据最近使用的区域全选图框
或画布。

## 科学摘要与备注

Plotium 会在画板中每个页面的下方自动概述当前绘制的数据。对于多 Panel 页面，
共同信息只显示一次，其余内容跟在相应的 Panel 标签后。

打开 **Canvas settings** 可以添加页面备注；也可以选中 Panel 后编辑其
**Note**。备注显示在摘要之后，不会包含在导出结果中。使用
**Show summary below page** 可以显示或隐藏整个画板专用信息区块。

## 使用图版面板

使用 Arrange 菜单或命令面板中的 Panel 命令，可以制作多 Panel 图版。你可以创建
空 Panel、把所选对象组成 Panel，也可以复制、合并、拆分、解散或删除 Panel。
在 Layers 中展开 Panel，即可查看其中的对象。

单击 Panel 内任意位置可将其选中，随后可以拖动整个 Panel，或用四角控制点连同
其中内容一起缩放。按住 `Shift` 单击可选择多个 Panel。若要编辑 Panel 内的对象，
请双击 Panel 或按 `Enter` 进入。点击页面上方的面包屑或按 `Esc` 可返回页面。也可
按住 `Ctrl`/`Cmd` 单击对象，无需先进入 Panel 即可直接选择它。
缩小时，若其中某张图的数据区会被坐标轴、刻度和色标挤占，缩放就会停在那里。
移动或缩放 Panel 或图时，它的绘图区也会吸附到其他图的绘图区边缘；即使刻度标签宽度
不同，坐标轴也能对齐。

关闭 **Clip contents to panel** 时，内容可以超出 Panel 和页面边界；拖动可见内容即可
将它移回。开启裁剪时，拖动或缩放会确保内容在 Panel 内仍可选中。对象重叠时，
拖动会作用于最上层的可见对象。

若要交换同一 canvas 中的两个 Panel，将其中一个拖到另一个上面，待两个位置高亮后
松开。两个 Panel 会交换位置和尺寸，内部内容随目标框缩放；整个交换可一步撤销。
隐藏或锁定的 Panel 不能作为交换目标，多 Panel 拖动仍保持整体移动。

在 Panel 内，对象会吸附到 Panel 边缘和其他对象。若要把对象移入另一个未锁定的
Panel，请将它拖到目标 Panel 上，待目标高亮后松开。也可以在 Layers 中把对象行
拖到 Panel 行。若目标采用 Stack 或 Grid 布局，内容会在移入后重新排列。隐藏对象
仍可在 Layers 中选择；锁定对象可以选择，但不能编辑。

对象检查器中的 Panel 设置可控制可见性、锁定、裁剪、标签和布局。**Vertical
Stack**、**Horizontal Stack** 与 **Grid** 会按选定的间距、内边距和对齐方式排列
内容；**Shared X Stack** 把多张图上下堆叠在同一条 x 轴上，见
[共享 x 轴堆叠](#共享-x-轴堆叠)。页面有多个可见 Panel 时，自动字母标签才会出现，并按阅读顺序排列：从上到下
逐行排列，同一行内从左到右。移动或添加 Panel 后，字母会立即更新。选择
**Locked auto** 可保留 Panel 当前的字母，取消 **Participates in sequence** 可让它
不参与编号、不显示字母。标签位于图片上时会自动切换黑白颜色以保持清晰；图的 y 轴标题
会在需要时自动下移，避免与字母重叠；若图太矮无法下移，整幅图会移到字母右侧。手工标签和锁定
标签在单 Panel 页面中仍会显示。
若要一次隐藏页面上的所有字母，请在 **Canvas settings** 中取消
**Show panel letters**；字母会保留原有编号，重新开启后恢复原样，隐藏期间
轴标题也不再为其预留空间。

将单个 Panel 完全拖离所有 canvas，并在外部持续停留 0.5 秒，即可准备新建 canvas。
预览会先显示进度条，随后变为绿色边框，并显示 **Release to create canvas**。
此时松手，整个 Panel 会移入当前位置新建的 canvas，页面尺寸与 Panel 一致。
内容、标签、备注和内部布局均保留，源 canvas 保持原位；移动和新建可一起撤销。
Panel 任一部分重新进入 canvas 都会重置计时。调整尺寸或拖动多个 Panel 时不会
新建 canvas，按 `Esc` 可取消拖动。

## 画布尺寸

活动页面左上角上方会显示一个尺寸标签，内容为当前尺寸和匹配到的预设
（例如 *89 × 60 mm · Nature · Single column*）。点击它、在 Figure Ribbon
选项卡中使用 **Canvas Size & Settings…**，或在命令面板中运行任意
"Canvas Size" 条目，都可以更换尺寸。

预设列表支持搜索并按组显示：期刊图幅宽度（Nature、Science、Cell Press、
ACS、Elsevier、PNAS 和 IEEE，数值取自各出版社的作图规范）、纸张尺寸
（支持纵向/横向切换）、演示文稿幻灯片、最近使用过的条目，以及你自己保存
的自定义尺寸。期刊预设只锁定页面*宽度*——高度由内容决定，上限为该期刊
的最大图幅深度；页面超过该深度时会显示警告。

默认情况下，更改尺寸不会移动或缩放内容；如果对象超出页面，尺寸标签一栏
会出现溢出警告，单击即可把内容等比缩小到页面内（可撤销，字号保持物理磅
值不变）。勾选 **Scale content when applying sizes** 后，应用预设时对象
会随页面一起缩放。

另有两项自动辅助：

- **Auto height**（自动高度）保持宽度不变，页面高度跟随内容深度变化，
  并以期刊最大深度为上限。
- 当布局网格设置为两列及以上、而页面仍是单栏宽度时，会出现一条可关闭的
  提示，单击即可切换到同一期刊的全宽——它绝不会自行改变页面尺寸。

导出对话框会预先选中匹配的期刊预设，因此按栏宽制作的页面默认按该宽度
导出。

## 分图之间的间距

多分图的版面，只有各分图的数据区间隔均匀才好看；但每个图为刻度标签和
轴标题预留的空间各不相同，图框等距往往看起来并不等距。
**Canvas Size & Settings…** 里既设定想要的间距，也设定它按什么来量。

**Minimum spacing**（最小间距）就是这个间距本身，单位与画布一致；
**Tight**（2 mm）、**Normal**（5 mm）、**Spacious**（10 mm）三个预设可
直接填入常用值。

**Spacing basis**（间距依据）决定这个间距量的是哪两处之间：

- **Visual**（默认）量的是相邻两图数据区之间的距离，并把夹在中间的刻度
  标签和轴标题计算在内，因此 y 轴标题较长的分图能自动获得所需空间。该值
  是下限：实际间距只会更宽，不会更窄，图框也不会重叠。相邻两图的轴文字
  之间始终至少相隔 8 pt。
- **Frame** 量的是图框之间的距离，不计轴文字。图框会严格按设定值排开，
  但各对分图数据区之间的可见空隙会随标签长短而变化。

图框止于最外侧的文字、刻度或轴线，自身不再留空白边。因此贴着页面边缘的
分图会直达导出图的边缘，适合页面即成品图的期刊尺寸。

凡是由 Plotium 自动摆放图形的场合都遵循该依据——**Apply grid**，以及把图形
拖到已有图形的页面上时的自动平铺。

把图拖到另一页面，即把它移到该页并重新平铺目标页。拖动过程中图形跟随
指针移动，按下时抓住的那一点始终停在光标下，目标页面上同时画出松手后
各图所在的位置。若目标页面上已有两个及以上的图，整页会重排成均匀网格，
拖入的图落在指针所指的那一格里。

如果这次移动把源页面清空，Plotium 会随本次拖放一并删除该页面，移动与删除
同属一步撤销/重做。释放鼠标时按住 `Alt` 则保留这个空页面；操作历史窗口会提示
当前这次拖放按住 `Alt` 会变成哪种结果。若希望默认保留空的源页面，可在
偏好设置 → General 中打开 **Keep source canvas when tiling its last
object**——此后按住 `Alt` 就只为这一次拖放删除空页面。

使用 Select 工具时，每条非零页边距都会画成一条贯穿页面的虚线，标示出正在
排版的内容区；设为 0 的一边不画线。打开布局网格会另外显示单元格轮廓，
拖动时出现的吸附参考线使用对比色。

## 精简内侧轴

一格格分图共用同一套坐标轴时，每个分图都重复刻度数字和轴标题只会浪费
版面。**Simplify Inner Axes**（精简内侧轴）只在每列最下方的图上保留 x 轴
文字，只在每行最左侧的图上保留 y 轴文字；轴线和短刻度在所有分图上都保留。

两种用法：

- 在画布设置中勾选 **Apply grid** 旁的 **Simplify inner axes**，排布与精简
  合并为一次可撤销的操作。图框会按精简后的坐标轴重新丈量，因此各分图能
  占用原先被隐藏文字占据的空间。
- 对已经排好的图形，可从 Arrange Ribbon 选项卡、画布右键的 Arrange 菜单
  或命令面板运行 **Simplify Inner Axes**。它要求至少有两个图形已对齐成
  网格；否则操作历史窗口会提示需要先做什么。

若要让某个分图重新显示文字，选中它后在对象检查器的 **Axes** 区域操作：
**X text** 与 **Y text** 两行可分别切换 **Tick labels** 和 **Title**，
**Automatic** 则让该轴恢复为两者都显示。

## 共享 x 轴堆叠

Shared X Stack（共享 x 轴堆叠）把一个 Panel 里的两张及以上的图上下排列、共用
一条 x 轴，例如 XRD 主图加下方的标准卡竖线图，或把几条光谱分开摆放。每张图保留
自己的 y 轴、图例和图型。

有两种进入方式：

- 选中装有两张及以上图的 Panel，在 Panel 检查器的 **Layout** 列表、
  **Edit ▸ Panel** 菜单或命令面板中选择 **Shared X Stack**。
- 选中多个各装一张图的 Panel，运行 **Stack with Shared X**：这些 Panel 会合并到
  第一个 Panel 中，并按页面上的上下位置堆叠，整个操作一步撤销。

堆叠后：

- 各图填满 Panel 宽度，内部边界上下紧贴。间距初始为 0 pt；在 Panel 检查器中调大
  **Gap** 可以分开摆放，同时保持对齐。
- 所有图的绘图区共用同一条左边缘和右边缘，无论 y 刻度数字多宽，y 轴标题都在一条
  竖线上。每张图各自决定是否有右 y 轴，有右轴的图的右轴标题也同样对齐。
- 只有最下面的图绘制 x 刻度数字和 x 轴标题，只有最上面的图绘制图标题。两张图
  相接处的 x 刻度朝内；最下面的 x 轴保持你设定的刻度方向。下方图 y 轴的 ×10ⁿ
  倍数移到其绘图区左上角内侧，落在共用边界上的 y 刻度数字不再绘制。
- 各图共用一个 x 视窗。进入堆叠时，会给每张图设置一个覆盖全部数据的 x 范围，
  并统一使用最上面那张图的 x 主刻度间隔，因此各图须先使用相同的 x 刻度类型（线性或对数）。所有图都跟随最下面那张图的
  x 方向：ppm 轴从右到左的 NMR 谱堆叠在升序图上方时，会改为从左到右绘制。
- 在任一张图上缩放或平移 x，其他图会一起移动。在任一张图上修改 x 范围、对数刻度、
  x 显示单位、千位分隔符或主刻度间隔，会同时改到堆叠中的所有图，并合为一次撤销；若其中某张图
  不接受该修改（例如 NMR 谱不能使用对数轴），整个修改会被拒绝。
- 从上到下的顺序就是 Panel 内容顺序。每张图的高度决定它在堆叠中所占的比例：在
  画布上拖动某张图的下边框，即可让它比其他图更高或更矮。
- 整个堆叠是一个 Panel，只有一个面板字母。

画布、操作历史中的检查以及所有导出都使用同一套堆叠几何。要退出堆叠，把布局改回
**Free** 或 **Vertical Stack** 即可，各图会重新绘制自己的 x 轴和 x 方向。共用的
x 范围会保留，直到你把 **X range** 改回 **Auto**。

## 使用 AI 客户端

也可以让连接到 Plotium 的 AI 客户端替你完成，例如：

> 把这一页改成 180 × 90 mm，把这两个 Panel 左右排开，页边距 4 mm、间距 5 mm，标上 a 和 b，先给我看预览。其他 Panel 不要动。

Plotium 只修改你指定的 Panel，整个排版是一步 Undo；之后每张图和每段文字都还能继续编辑。
同意之前请先看预览。参见[权限、审阅与撤销](/zh-cn/ai/control-and-review/)。

图形完成后，见[导出](/zh-cn/guides/exporting/)。
