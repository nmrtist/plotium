## 添加图片

若要让每张图片各占一个适配大小的页面，请从 File 菜单、Ribbon 或命令面板选择
**Add Images…**。一次可以选择多张 PNG、JPEG、TIFF、WebP 或 BMP 图片。Plotium 按文件内容而不是扩展名
判断格式。不支持 GIF 和 SVG 图片。也可以
直接把文件拖到画板上；即使落点位于已有页面内，每张图片仍会新建一个页面。

图片超过 1 亿像素或预计解码后超过 512 MiB 时，Plotium 会要求确认；超过 5 亿像素或
2 GiB 的图片会被拒绝。

若要把图片放进已有 Panel，请先选中或进入未锁定的 Panel，再把文件拖入绿色轮廓。
若要粘贴图片或复制的一组图片文件，请使用 **Paste Image**，或按 `Ctrl`/`Cmd` +
`V`。在 Windows 上，可以从文件资源管理器复制文件，也可以从 Paint 等应用复制
图片像素。光标位于文本框中时，该快捷键仍会正常粘贴文本。

Plotium 创建图片页面时，会优先采用图片的 DPI 信息确定实际尺寸；没有 DPI 信息时按
96 DPI 计算。页面宽度不超过 89 mm，高度保持图片的原始宽高比，图片会无变形地
铺满页面。一次导入多张图片只产生一个撤销步骤；导入失败或取消不会改动项目。

以下格式需要使用专门的命令：

- **Add Animated Image First Frame…** 导入动画 PNG 或 WebP 的第一帧。用
  **Add Images…** 添加动画图片时，Plotium 会提示它是动画。
- **Add Images Without Metadata…** 先把图片转换为 PNG，以去除元数据，再添加到项目。
- **Add All TIFF Pages…** 添加多页 TIFF 中所有可读取的页面；常规的 **Add Images…**
  只添加第一页。

## 调整图片

选中图片后，可在对象检查器的 **Image**
区域裁剪或旋转图片、调整透明度，或选择插值方式。这些调整不会改变嵌入的源图片。图片保存在 `.plotium` 项目中；复制图片不会复制其
存储的源图，每个副本各自保留裁剪、旋转、透明度、适配和插值设置。

画板使用有内存上限的代理图以保持编辑流畅；SVG、PDF、EMF、PNG、JPEG、TIFF
以及 **Copy Figure** 则从项目中嵌入的原图采样。裁剪、90 度旋转、透明度、适配、
插值、Panel 裁切和图层顺序都会与画板一致，也不依赖源文件原先所在的路径。

## 图片缺失或损坏

打开项目时，Plotium 会校验每张嵌入图片。若图片缺失、损坏或与记录不符，项目仍会打开，并在原位置保留带说明的占位项。请在对象
检查器中使用 **Replace Image…** 修复。替换前，常规保存和出版导出会停止；若仍需
生成审阅稿，可在导出对话框中明确允许输出带标签的占位图。

导出对话框对图片所做的检查见[导出](/zh-cn/guides/exporting/#导出图形)。

## 使用 AI 客户端

也可以让连接到 Plotium 的 AI 客户端替你完成，例如：

> 把 /Users/me/images/sem.png 这张显微图放进 Panel b，按 Panel 大小适配，先给我看预览。

AI 可以添加本地的 PNG 和 JPEG 文件，每个文件不超过 1 MiB（解码后不超过 4 MiB），
请告诉它文件的完整路径。更大的图片请自己用 **Add Images…** 添加。修改会立即出现在
Plotium 里，是一步 Undo。同意之前请先看预览。参见[权限、审阅与撤销](/zh-cn/ai/control-and-review/)。
