---
title: 权限、审阅与撤销
description: 控制 AI 客户端能做什么，跟随和撤销它的修改，以及排查连接问题。
---

AI 客户端在 Plotium 中做什么由你掌控：你决定它能否修改内容，每项修改都能撤销，
没有你在 Plotium 中确认，它不会向磁盘写任何文件。

## 决定 AI 能做什么

在 **Preferences → AI connections (MCP)** 中设置，或点击 Ribbon 中的机器人图标。

| 设置 | 作用 |
| --- | --- |
| **Access → Read only** | AI 可以查看数据、表格和图形（包括当前图形的图片），但不能准备、预览或应用修改。切换为只读还会阻止它已准备但尚未应用的修改 |
| **Access → Read and modify** | AI 还可以做支持的修改。这是默认设置 |
| 关闭 **Enable MCP** | 立即停止所有访问，丢弃 AI 已准备但尚未应用的修改，保留客户端配置 |

权限设置对所有已连接的客户端和你打开的每个项目生效，Plotium 会在重启后记住它。关闭
偏好设置或切换项目不会断开连接；退出 Plotium 则停止访问。重启后可以继续使用原来的
AI 对话，无需再次添加客户端。切换项目后，请先让 AI 查看当前项目，再继续编辑。

你的 AI 客户端可能也会请你批准它的工具调用。那是客户端自己的审批，与 Plotium 的
权限设置相互独立：在客户端里批准调用，不会绕过 **Read only**，也不会免去保存和
导出确认。

## 审阅和撤销修改

- 每项修改都会立即出现在 Plotium 中，无论涉及多少内容，都是 **Undo** 和 **Redo**
  中的一步。保存和导出不是对项目的修改，不能撤销。
- 你手动设置的值，例如在对象检查器中选的颜色或拖动过的图例，在 AI 重新设置样式或
  套用主题时会保留，除非你要求修改。
- 查看、预览和检查不会改变项目，也不会使项目变为未保存。
- **操作历史**（Ribbon 中的时钟箭头按钮）在 **Results** 中列出最近 AI 操作的结果，
  并提供查看链接。

## 保存和导出确认

AI 请求保存或导出时，Plotium 会显示 **Allow AI to save this project?** 或
**Allow AI to export this figure?**，并列出具体文件路径。

- 点击 **Allow save** 或 **Allow export** 继续，或点击 **Deny**，不写入任何文件。
- 替换已有文件需要在同一提示中另外勾选。
- 每次确认只对这一次请求有效；路径变了需要重新确认。
- 即使是 **Read and modify** 权限也需要这项确认；**Read only** 下 AI 也可以请求它。

保存记录的是你允许那一刻的项目，之后的编辑仍未保存。导出不会改变项目，也不会使
项目变为已保存。

## 跟随 AI 结果

默认情况下，工作区会跟随 AI：显示最近一次完成的操作所影响的画布。一次操作影响多个
画布时一起显示；已在视图中的画布保持缩放。只查看项目的请求和空画布不会移动工作区。

AI 连接按钮旁的跟随按钮显示跟随状态：活跃、暂停或关闭。你自己操作时跟随会暂停：
打开或选择其他内容、平移、缩放或编辑。悬停和查看操作详情不会暂停。在操作历史的
**Results** 中可使用 **Pause**、**Resume**、**Stop following** 或 **View latest**。

跟随暂停时：

- 跟随按钮上的角标计数尚未查看的新结果或更新结果。同一对象的多次修改只计一次。
  查看某个结果会把它标为已看；**View latest** 显示最新结果，但较早的结果仍留在
  计数中，也不会重新开启跟随。恢复跟随会清零计数。打开 **Results** 可以查看这些
  结果而不恢复跟随。
- 当前正在查看的对象发生更新时，也会显示可关闭的短暂提示。
- 会出现一个提醒，提供 **Resume following**、**Dismiss** 和 **Don't remind
  again**。它约八秒后自动关闭。**Dismiss** 只收起提醒，不会把结果标为已看；同一
  对象再次修改不会重新弹出提醒，出现新的结果对象时则会。**Don't remind again**
  会在重启后仍关闭这类提醒；可在 **Preferences → General → Remind me about results
  while following is paused** 中重新开启。结果计数和错误提示仍然保留。

暂停会立即冻结当前视图，包括尚未结束的自动缩放。恢复跟随或查看最新结果时，只显示
最近一次操作的结果。切换项目或连接断开会停止跟随；准备好后请自行恢复。跟随不会
取消正在运行的任务。

机器人图标上的旋转标记表示有科学计算任务正在运行。悬停可查看操作、已知的进度，以及
此时编辑是否可能导致结果无法应用。它表示 Plotium 自己正在运行的工作，不表示 AI
已经完成了你的请求。

## 机器人图标

将鼠标停在机器人图标上，可查看项目、权限和最近活动；点击可打开连接设置。Ribbon
折叠后仍可使用此图标。

| 外观 | 状态 | 含义 |
| --- | --- | --- |
| 灰色、短斜线 | Off（已关闭） | 需要连接时开启 **Enable MCP** |
| 蓝色、空心点 | Starting / Ready（启动中／就绪） | 等待启动，或从客户端发送请求 |
| 绿色、实心点 | Active（活跃） | 最近 30 秒有客户端活动；不代表它的任务已完成 |
| 橙色、感叹号 | Needs attention（需要处理） | 打开连接设置，查看错误并按提示处理 |

## 连接不成功时

| 遇到的情况 | 建议操作 |
| --- | --- |
| Plotium 找不到 Codex 或 Claude Code | 通过 **Installation help** 安装，或用 **Choose executable…** 选择客户端程序，再点击 **Add** |
| 错误提示缺少 Node.js | 检查客户端的 Node.js 安装，或选择独立的客户端可执行文件后重试 |
| 已有另一个名为 `plotium` 的服务器 | 先检查现有配置；确定要替换时点击 **Back up and replace this entry**。Plotium 会备份原条目，不改动其他服务器 |
| 显示 **Configured**，但没有客户端活动 | 重载客户端的 MCP 配置或重启客户端，再发送[首次请求](/zh-cn/ai/connect/#检查连接)；检查客户端是否禁用或阻止了该服务器 |
| AI 说项目已变化或它掌握的信息已过时 | 让它重新查看当前项目后再继续 |
| 提示连接由另一个 Plotium 实例提供 | 使用提供连接的实例，或退出该实例，让当前实例接入。切换窗口焦点不会切换 AI 访问的项目 |
| Windows 更新时提示连接器被占用 | 退出正在使用 Plotium 的 AI 客户端，再在连接设置中点击 **Retry** |
| 缺少连接器或 Claude Desktop 扩展 | 重新解压完整的 Plotium 发行包，将其中的文件保留在一起 |

启动失败后会自动重试。连接设置会显示最近操作和错误；解决原因后，如页面提供
**Retry**，可点击重试。

如果 AI 修改内容时连接中断，请先检查项目再让它重试：修改可能已经完成，再次执行
可能产生重复内容。保存和导出也一样：让 AI 查询那次请求的结果，而不是重新发送。
