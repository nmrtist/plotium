本页带你从数据一直走到导出的图。数据来自 NMR 谱仪等仪器时，从谱开始；数据是
CSV 或 Excel 文件时，从表格开始。两条路线最后都使用相同的排版、导出和保存步骤。

也可以让连接到 Plotium 的 AI 客户端先替你做出初稿，再在画板上自己细调；见
[连接 AI 客户端](/zh-cn/ai/connect/)。

## 从谱开始

### 1. 导入

把数据文件——例如 JEOL `.jdf`——拖到 Plotium 窗口上，或从 **File** 菜单
选择 **Open File…**。Bruker TopSpin 实验则使用 **Open Folder…** 并选中
实验目录。

数据集出现在主侧栏中，并自动放置到画板上，已在自己的页面里绘制完成。

### 2. 处理

打开 Ribbon 的 **Process** 页签。新的 1D 数据集已带有标准管线——切趾、
零填充、FFT、相位校正、基线校正——并默认启用自动相位，多数情况下屏幕
上的谱图已经可用。

该页签会在画布右上角打开处理卡片，按顺序列出这些步骤。在那里编辑即可：每次
修改都实时预览且可撤销。两处调整覆盖大部分场景：

- 基线起伏时，启用**基线校正**步骤。
- 自动相位不理想时，打开**相位校正**步骤，实时预览下调节 φ0 / φ1。

完整步骤列表见[数据处理](/zh-cn/guides/processing/)。

### 3. 分析

按 `P` 选择**峰**工具，拖动图上的阈值线：松开时高于阈值的峰会被检测出
来。自动检测不足的位置可手动添加、移动或删除峰标记。

提取出的数值——峰列表、积分、拟合参数——会进入与谱图联动的数据表。
本走查到峰拾取为止；[分析工具一览](/zh-cn/guides/choosing-a-tool/)介绍
其余工具及其适用场景。

接下来见[排版页面](#排版页面)。

## 从表格开始

### 1. 导入表格

在 **Data** 页签选择 **Import Table…**，选取 CSV、TSV 或 XLSX 文件；也可以用
`Ctrl` + `Shift` + `V` 粘贴复制的表格。**Review table import** 对话框会显示每列识别出的
类型和单位；核对后选择 **Import table**。列类型如何确定，见
[导入表格](/zh-cn/guides/importing-data/#导入表格)。

表格以数据表的形式出现在画板上，旁边是一个带空白图的新页面。

### 2. 选择列

单击图将其选中。在对象检查器中展开 **Data → Curve columns**，选择 **X** 和 **Y**
列，需要时再选 **Y error** 列，然后选择 **Apply curve binding**。曲线随即出现在图上。

要在同一坐标轴上再画一列，展开 **Add curve**，选择表格及其 **X**、**Y** 列，选
**Line** 或 **Scatter**，再选择 **Append curve**。

### 3. 选择图表类型

图一开始是折线图。要改成柱状图、直方图、箱线图或其他图表，在 **Figure** 页签选择
**Chart**，再从 **Chart type** 画廊中挑选。哪种图表回答哪种问题，见
[绘图与图表类型](/zh-cn/guides/plots-and-charts/)。

## 排版页面

点击页面左上角上方的尺寸标签（或 **Figure** Ribbon 页签的 **Canvas
Size & Settings…**），选择目标期刊的单栏预设。页面宽度会对齐到期刊的
制图规范；坐标轴文字已是印刷尺寸。

需要面板序号或标注时，按 `T` 选择文本工具并点击画布。见
[标注](/zh-cn/guides/annotations/)。

## 导出

使用 **Figure** 页签的 **Output** 分组（或 **File → Export**），选择矢量格式——SVG 便于继续编辑，PDF 适合投
稿——或栅格预设，例如 *Single column · 89 mm · 600 dpi · TIFF*。导出
预检会在写出前提示字号或线宽违反所选预设的问题。

要快速粘贴到文档里，`Ctrl` + `C` 会把所选图框同时以位图和矢量复制到
剪贴板。

## 保存项目

`Ctrl` + `S` 把一切——数据、处理、分析和排版——保存为一个 `.plotium`
文件，之后可以重新打开或发给同事。见
[Plotium 文件](/zh-cn/reference/file-formats/)。
