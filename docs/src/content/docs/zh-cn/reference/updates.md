## 自动更新

从 Plotium 0.2.0 开始，macOS 应用包和 Windows/Linux ZIP 安装均支持自动更新。
启用 **Automatic updates**（默认开启）后，Plotium 会定期检查更高版本，
下载对应安装包，并根据 GitHub 发行版元数据校验 SHA-256。
下载在后台进行，安装在 Plotium 退出后完成。

### macOS 应用包

将 Plotium.app 安装到 Applications 或其他可写的本地文件夹，推出 DMG 后再运行。
更新器下载对应处理器架构的 DMG，核对新应用的标识、版本、架构和代码签名，
退出后整体替换应用，包括 MCP 连接器、扩展、资源和应用包元数据。
替换失败时会尝试恢复旧应用。工程和偏好设置会保留。

macOS 可能要求授予更新应用的权限。安装位置不可写时，请将 Plotium 移到可写
本地文件夹，或从新 DMG 手动替换。直接从已挂载 DMG 或 App Translocation
文件夹运行的副本不能自动更新。安装更新前请退出其他正在运行的副本。

应用采用 **ad-hoc 签名且未公证**。这能校验应用包完整性，不能证明发布者身份，
也不代表通过 Apple 恶意软件审查。更新不会关闭 Gatekeeper 或移除隔离属性。
若 macOS 阻止新副本启动，请按[首次启动](/zh-cn/getting-started/installation/#首次启动)
处理。首次下载启动及未来的 macOS 策略仍可能要求用户操作。

### Windows 和 Linux ZIP 安装

更新器同步替换可执行文件、随包 MCP 配套文件及许可证说明。
请将解压后的文件保留在同一可写文件夹中。

## 检查与重启

更新下载期间，Ribbon 任务行右端会显示进度。更新就绪后，选择 **Restart to
update** 即可立即使用新版本。重启前，Plotium 会先询问如何处理未保存的
更改；取消关闭不会导致之后意外重启。如果正常关闭，更新会在退出后安装，
并在下次打开 Plotium 时生效。

**偏好设置 → 通用** 中可以查看当前版本和更新器状态，**Check now** 可
立即手动检查（命令面板中的 **Check for updates…** 亦可），页面里也有
**Restart now** 按钮。

后台检查失败（例如离线时）不会打扰你；只有你手动发起的检查才会显示
错误信息。退出后发生的安装错误会在下次启动的 **偏好设置 → 通用** 中显示，
可用 **Check now** 重试。若系统阻止重新启动，可改用手动下载安装。
若更新已安装，但清理临时文件或重新启动失败，这里会显示“Update installed”
提示；如有需要，请手动打开 Plotium。

## 发布通道

Plotium 提供三个发布通道：

- **Stable** 接收正式版本，适合大多数用户。
- **Beta** 可提前体验仍在测试的功能。
- **Alpha** 最早提供新版本，但可靠性可能较低。

在 **Update channel** 中选择通道。**Follow build** 会使用当前 Plotium
副本自带的通道。切换到更稳定的通道不会降低已安装的版本；Plotium 会等待
所选通道发布更高版本。

## 关闭自动更新

在 **偏好设置 → 通用** 中关闭 **Automatic updates** 即可停止所有后台
检查；**Check now** 手动检查仍然可用。
