		Peaks, integrals, DOSY / relaxation and IV analysis, curve fitting
		with custom models, and classical statistics — all feeding linked
		data tables.
	</Card>
	<Card title="Publish" icon="document">
		Arrange figures on an infinite board and export to SVG, PDF, PNG, or
		TIFF at publication-quality presets.
